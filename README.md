Full-stack multi-role venue booking platform for party halls across India.
- **Django + Next.js 14 + PostgreSQL+PostGIS** with pincode-based geolocation via MapLibre GL JS
- **Celery + Redis** for async slot cleanup, email reminders, and subscription expiry
- **Razorpay/Cashfree** payment integration with HMAC-SHA256 webhooks and XSS-safe JWTs
